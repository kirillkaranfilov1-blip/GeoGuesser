# 🌍 GeoGuesser

Интерактивная игра-викторина о странах мира, созданная с использованием **HTML, CSS и JavaScript**.

Игроку показывается фотография известного места или достопримечательности, после чего необходимо выбрать страну, в которой она находится.

## 🎮 О проекте

**GeoGuesser** — небольшая браузерная игра для проверки знаний географии.

В каждом вопросе игроку показывается изображение, вопрос и несколько вариантов ответа. После выбора варианта игра определяет правильность ответа и переходит к следующему вопросу.

## ✨ Возможности

* 🌎 Вопросы о разных странах мира
* 🖼️ Изображения известных достопримечательностей
* 🔘 Несколько вариантов ответа
* ✅ Проверка правильного ответа
* ❌ Определение неправильного ответа
* 📊 Подсчёт результата
* 🔄 Переход между вопросами
* 🎨 Современный пользовательский интерфейс
* ✨ Плавные анимации
* 📱 Адаптация интерфейса под разные размеры экрана
* 🎬 Анимации с использованием GSAP
* 📝 Вопросы хранятся в JavaScript-массиве

## 🛠️ Используемые технологии

### HTML5

Используется для создания структуры приложения:

* игровое поле
* блок вопроса
* изображение
* варианты ответов
* кнопки управления
* результат игры

### CSS3

Используется для оформления интерфейса:

* Flexbox
* Grid
* адаптивная верстка
* hover-эффекты
* transitions
* animations
* современные UI-компоненты

### JavaScript

Отвечает за основную игровую логику:

* загрузку вопросов
* отображение изображений
* генерацию вариантов ответа
* проверку ответов
* подсчёт очков
* переход между вопросами
* завершение игры

### GSAP

Используется для создания плавных и современных анимаций интерфейса.

### SplitText

Используется для анимации текста и появления элементов интерфейса.

## 🧩 Формат вопроса

Все вопросы хранятся в массиве JavaScript.

Каждый вопрос содержит:

js
{
    image: "./img/France.jpg",
    question: "В какой стране находится Эйфелева башня?",
    options: ["Италия", "Франция", "Испания", "Германия"],
    answer: "Франция"
}
